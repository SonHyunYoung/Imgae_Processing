# 1차 과제. 미니 포토샵 만들어보기 도전문제

## 기존 소스코드에서 수정한 것

1. clone을 전역변수로 선언함. 이 코드에서 clone은 원본 이미지를 깊은 복사해서 저장해놓은 코드로, 원본을 저장한 변수임. 원본 저장소 용도로 사용
2. 마우스가 움직일 때 이벤트를 추가함. 이는 마우스가 움직일 때도 현재 네모가 어느정도 크기인지 표시하기 위함
3. c를 입력할 때 지정된 영억이 없으면, crop이 작동되지 않게 하였음. 또한 크롭한 결과를 보여줄 때 밝기를 조절함
4. 만약 다시 네모를 그린다면 기존에 그린 네모를 지우고 다시 그리는 네모만 표시되게 함.
5. d를 입력하면 네모를 그린 후 다시 클릭하지 않아도 사진을 초기화 할 수 있게함.
6. 위에서 아래방향만이 아닌 아래에서 위로도 네모를 그릴 수 있게함.

## 어떻게 변경하였나?

1. 마우스 버튼을 누른 채로 움직일 때 사각형이 표시되도록 프로그램을 수정<br>
  ==> `EVENT_MOUSEMOVE`를 통해 마우스가 움직일떄도 네모를 그리도록 함. 이때 clone 해놓은 원본을 먼저 띄우고 그 위에 계속해서 네모를 그림(마우스가 이동할 때 마다)

2. 사각형은 선택하면 이전의 사각형을 영상에서 지운다. <br>
   ==> `EVENT_LMOUSEBUTTONDOWN`을 처리하는 과정에 클릭이 발생하면 clone해놓은 새 이미지를 띄우게 하고 클릭한 위치를 저장하도록 함. 새 이미지를 띄우는 것만 수정

3. 네모를 그릴때 어떤 방향으로도 그릴 수 있게 수정 <br>
    ==> Rect 클래스를 이용해 해결. Rect 클래스로 위치를 저장할 때 Point를 이용해 위치가 음수가 되도 자동으로 처리할 수 있게함.

4. c를 입력할 때 아무런 영역이 지정되지 않으면 크롭이 진행되지 않음. <br>
   ==> Rect 이용, Rect 객체를 생성 후 위치를 저장한다. 만약 이 객체의 width나 height가 0이면 지정된 영역이 없음을 알림. (콘솔 내에서)
   
6. d를 입력하면 사진 클릭없이 사진 초기화 <br>
   ==> d를 입력할 시 clone 해놓은 사진 보여줌

7. 크롭한 사진을 약간 보정해서 보여줌 <br>
   ==> convertTo 함수를 이용해서 밝기를 보정함

## 코드 작성하면서 햇갈렸던 부분

 이 코드는 img가 원본이고, 이를 clone에 복사해서 사용함. 이때 clone은 계속해서 원본을 보여주는 역할을 하기 때문에 clone에서 네모를 그리는 활동을 수행하는 것이 아님. 네모를 그리고 띄우는건 모두 img에서 처리되는데 이를 반대로 이해했었음.
